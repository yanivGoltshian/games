# הרפתקת למידה

אפליקציית PWA מקומית, חמה וידידותית למגע לילדים צעירים שעדיין אינם קוראים. הפרויקט בנוי ב־Vite + React + TypeScript, מותאם קודם כול לאייפד ולטלפון, וכולל שמונה משחקים פעילים עם התקדמות אדפטיבית מקומית בלבד. באזור המבוגרים אפשר להגדיר שם אישי ולהוסיף תמונות משפחתיות לפאזלים; הכול נשמר רק במכשיר.

## פקודות

```bash
npm install
npm run dev
npm run test
npm run lint
npm run typecheck
npm run build
npm run preview
```

לבדיקת הפריסה של שני משחקי הזוגות, מריצים את גרסת הבנייה על כתובת מקומית בלבד. הבדיקה משתמשת בהתקנה נפרדת של כלי האוטומציה, פותחת את דפדפן כרום של גוגל בפרופיל מבודד, ושומרת מדידות וצילומי מסך עם התקדמות מדומה.

```bash
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
  node scripts/check-pair-layout.mjs http://127.0.0.1:4173 /tmp/pair-layout
```

לבדיקת יציבות המסך, מחליקים באצבע מדומה לשני הצדדים בבית ובכל משחק, גוררים חלק פאזל ופריט מיון וגוללים באזור המבוגרים. הבדיקה רצה בכרום במידות טלפון ואייפד לאורך ולרוחב. היא בודקת את תוכן האפליקציה, לא מחוות ניווט של מערכת ההפעלה בקצה המסך.

```bash
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
  node scripts/check-viewport-touch.mjs http://127.0.0.1:4173
```

## התקנה על אייפד (הערה למבוגרים בלבד)

### Safari
1. פותחים את האפליקציה.
2. לוחצים על כפתור השיתוף.
3. בוחרים **הוספה למסך הבית**.
4. מאשרים את השם “הרפתקת למידה”.

### Chrome באייפד
1. פותחים את התפריט או Share.
2. בוחרים **Add to Home Screen**.
3. מאשרים את ההתקנה.

אחרי טעינה ראשונה, ה־service worker שומר קבצים מקומיים כך שאפשר לשחק גם בלי חיבור רשת. כל ההערות האלה על התקנה, אופליין וקול מופיעות רק במסך המבוגרים באפליקציה עצמה (אזור למבוגרים), ולעולם לא במסך הילד.

## מה יש בפנים

- **בית לילד**: כל שמונת הפורטלים גלויים יחד במיקומים יציבים. אין משחקים נעולים ואין צורך לגלות מחוות החלקה. כל פורטל הוא כפתור מגע גדול עם סצנה ויזואלית ייחודית והשקה בלחיצה אחת.
- **8 משחקים פעילים**, עם רמה 1 מוגבלת בכוונה למספר קטן של פעולות וברירות:
  - שומעים ובוחרים
  - כמה יש?
  - ממיינים צבעים וצורות
  - פאזל קטן עם snap סלחני
  - זוגות זיכרון: בכל כניסה מתחילים בשני זוגות. כל לוח שהושלם מוסיף זוג אחד, עד שמונה זוגות. חיפוש שכולל טעויות עדיין נחשב. אפרסמון, תמרים ומשפך מופיעים כבר בשלבים הראשונים.
  - זוגות מספרים: בכל כניסה מתחילים בשני מספרים בכל קבוצה. כל לוח שלם מוסיף מספר שונה אחד לכל קבוצה, עד עשרה. במסך צר כל קבוצה יכולה להתפרס על יותר משורה אחת. בשני משחקי הזוגות הכוכבים וההתקדמות המצטברת נשמרים גם כשחוזרים ללוח הקטן.
  - החייזר המבולבל, שפועל ללא מגע אחרי ההפעלה
  - גן המילים: שישה סיפורים בני ארבעה משפטים על בננה, תמר, אבוקדו, תות, גזר ותפוח. בכל כניסה סדר הסיפורים מתערבב, אבל המשפטים בכל סיפור נשארים בסדרם. שון פותח את הסיפור; בהמשך גם השורש, הדבורה או הגשם פועלים. נוגעים בשלושה קלפים לפי סדר הקריאה. הקריינית שואלת, מחכה ומדגימה; בנגיעה בקלף הפעולה רואים את הפעולה בגדול בלי להסתיר את הקלף הבא. אחרי המשפט השלם הרכבת נוסעת לתחנה וממשיכה מאליה, ואפשר גם לעבור בנגיעה. אפשר לשחק בלי לדבר, בלי קול או בתנועה מופחתת.
- **פאזלים מתמונות משפחתיות מקומיות**: מבוגר יכול לבחור תמונות דרך בורר התמונות או הקבצים באייפד. לפני פענוח הפיקסלים נבדקות מידות התמונה מתוך מבנה הקובץ, ותמונה גדולה מכדי לעבד בבטחה נדחית. הדפדפן מפענח את התמונה ישירות לגודל מוקטן כשהמכשיר תומך בכך, מצייר מחדש את הפיקסלים בכיוון הנכון, מגביל את הצד הארוך ל־1600 פיקסלים ושומר עותק JPEG חדש ב־IndexedDB. קובץ המקור, שם הקובץ, EXIF, מיקום ופרטי מקור אחרים אינם נשמרים. הספרייה מוגבלת ל־24 תמונות, זמינה אופליין רק באותו מכשיר ומופיעה רק באזור המבוגרים ובתוך משחק הפאזל.
- **מסך משחק לילד**: משימה אחת ברורה בכל זמן נתון, ובראש המסך רק שני כפתורים גדולים – חזרה לבית והשמעה חוזרת. שער המבוגרים אינו מופיע כלל בתוך משחק.
- **שפה חזותית מקומית**: תמונות מושגים, איורים מקוריים לגן המילים ולזיכרון, וספריית ציורים מקומית. בננה שלמה ונגוסה הן שני מצבים של אותה פעולה, לא שני זוגות זיכרון. גן המילים נפתח ישירות למשחק עם האיור המקורי של שון בקלף הדמות ובקלף הפעולה. המשחק שואל ״מי בתמונה?״. אפשר לבחור תמונה חלופית בספרייה שבאזור המבוגרים; הבחירה נשארת באחסון המקומי של האפליקציה, ואם התמונה לא זמינה, האיור המובנה מוצג במקומה.
- **חגיגת הצלחה עדינה**: כל תשובה נכונה מציגה חיזוק לא־חוסם עם המסקוט, קונפטי, צליל וריטוט אופציונלי. המעבר לסיבוב הבא מתרחש רק אחרי שהיעד והשבח סיימו להישמע, או בלחיצה מפורשת להתקדמות. לאחר רצף הצלחות קטן מופיעה חגיגה מעט עשירה יותר – בלי לחץ ובלי מונים.
- **שבחים מרכזיים ודטרמיניסטיים** ב־`src/content/praise.ts`: מזהים יציבים, בחירה טהורה ונבדקת (`praise.test.ts`), עברית ואנגלית תואמות לשפת הלמידה הפעילה, ורצף דיבור שתמיד משמיע קודם את שם היעד/התשובה ורק אז את השבח.
- **עידוד לימודי אחרי ניסיון נוסף**: אין צליל כישלון, סימון אדום או שפה של טעות. כל משחק מציג רמז חזותי עדין, משמיע קודם מודל קצר ורלוונטי ורק אחריו משפט עידוד מתחלף. במשחק הספירה סופרים יחד ומדגישים כל עצם בתורו; בזיכרון אי־התאמה מוצגת כחלק טבעי מהחיפוש.
- **התקדמות אדפטיבית** ב־localStorage: ניסיונות, הצלחות, רמת שליטה, עלייה עדינה ברמה וחזרה על מושגים חלשים – מוצגת רק במסך המבוגרים.
- **אזור למבוגרים** שנפתח בלחיצה ארוכה של כ־2.7 שניות על גלגל השיניים, ורק שם.
- קול דרך SpeechSynthesis, צלילי חיזוק דרך Web Audio, ריטוט קליל אופציונלי, מצב שקט, פחות תנועה (גם לפי הגדרת מבוגר וגם לפי `prefers-reduced-motion`), והגדרות שפה.
- PWA מקומי בלבד, בלי אנליטיקות, בלי חשבונות ובלי קישורים חיצוניים.

## ארכיטקטורה קצרה

- `src/art` ו־`public/assets/vocabulary` – ספריית אמנות מקורית לממשק ולחגיגות לצד אוצר מילים פוטוריאליסטי מקומי שנוצר במיוחד עבור האפליקציה. כל מושג לימודי וסצנת פאזל משתמשים בתמונה מציאותית עם מזהי `data-content-id` ו־`data-art-id` יציבים.
- `src/content` – מטא־דאטה מרכזי למושגים, משחקים, סצנות פאזל, בנק שבחים ובנק עידוד מקומי עם מזהים יציבים.
- `src/domain` – RNG דטרמיניסטי, לוגיקת סיבובים (כולל אילוצי רמה 1), דקדוק כמויות, מדרגות רמז, התקדמות, ולידציה/מיגרציה של persistence.
- `src/services` – שמירת התקדמות ב־localStorage, ספריית תמונות פרטית וממוסגרת ב־IndexedDB, המרת תמונות מקומית דרך פיקסלים, תור הקראה סדרתי עם מזהי בקשות/עדיפויות, איחוד משוב כפול ורצפי "מודל ואז עידוד" ו"יעד ואז שבח" שממתינים לסיום אמיתי, וצלילי חיזוק/ריטוט.
- `src/components` – מעטפת UI לילד (בית, מסגרת משחק, חגיגת הצלחה), שער למבוגרים, פאנל מבוגרים, עזרי גרירה משותפים.
- `src/games` – שמונת משחקי הילד.
- `public/sw.js` ו־`public/manifest.webmanifest` – יכולות PWA ואופליין.

## פרטיות

כל המידע נשמר רק על המכשיר המקומי. אין שרת, אין שליחת נתונים, אין איסוף אנליטיקות, אין חשבונות ואין אחסון חיצוני. תמונות מיובאות אינן מועלות, מסונכרנות, נרשמות ללוגים או נכנסות למטמון ה־service worker. רק עותק JPEG שנבנה מחדש מפיקסלים וללא מטא־דאטה נשמר ב־IndexedDB המקומי; מחיקתו באזור המבוגרים מסירה אותו מן האפליקציה.

גן המילים אינו מפעיל את המיקרופון ואינו בודק מה הילד אמר. המשחק מתקדם במגע גם בשתיקה או במצב שקט. רק באזור המבוגרים, בלחיצה מפורשת על ״התחלת הקלטה״, אפשר להקליט משפט בשפה הנבחרת. אפשר להאזין לטיוטה לפני השמירה, להחליף או למחוק הקלטה. רק המשפט המלא מושמע בקול ההורה; השאלות והדגמת המילים נשארות בקול הקריינית. ההקלטות נשמרות באחסון מקומי בלבד. מחיקת התקדמות אינה מוחקת תמונות והקלטות; אפשר להסיר אותן באזור המבוגרים.

## גישה מבוססת־ראיות, לא קלינית

העיצוב הפדגוגי של האפליקציה שואב השראה ממקורות חינוכיים ומקצועיים ציבוריים על התפתחות שפה, דו־לשוניות ומסכים אצל פעוטות. הרשימה הבאה **אינה ממצה, אינה מהווה אישור, הסמכה או המלצה קלינית** מצד הגורמים המוזכרים, ואינה תחליף לייעוץ של איש/אשת מקצוע (למשל קלינאי/ת תקשורת, רופא/ת ילדים או גורם חינוכי מוסמך). האפליקציה אינה מציגה ואינה מתיימרת להציג אבחון, טיפול או ניטור התפתחותי.

### שיחה ומשחק משותף בעולם האמיתי

שום אפליקציה, כולל זו, אינה תחליף לשיחה, הקראה, ומשחק משותף עם מבוגר. הסיבובים במשחקים קצרים בכוונה, ואחרי רצף הצלחות קטן מופיעה חגיגה עם רגע חזותי רגוע שמזמין לצאת לשחק יחד. מומלץ שההורה/המטפל יהיה נוכח, ישתתף וימשיך את החוויה בעולם האמיתי – שיחה, הצבעה על עצמים אמיתיים, חזרה על מילים וקריאה משותפת תורמות הרבה יותר מזמן מסך עצמאי.

## מנגנון הקריינות

בדפדפנים רגילים ההקראה משתמשת ב־SpeechSynthesis של הדפדפן (Safari/Chrome), ולכן:
- איכות הקול תלויה בקולות המותקנים במכשיר.
- ייתכן שבמכשירים שונים יהיו הבדלים בהגייה ובזמינות הקולות.
- אם אין קול זמין, המשחקים עדיין עובדים במלואם עם תמונות ומגע – שום דבר לא תלוי בקול בלבד.

השירות משמיע בקצב לימודי מתון (`0.72` בעברית, `0.76` באנגלית), בוחר קול מקומי תואם־שפה כשקיים, ומסדר את ההקראות בתור יחיד. עדכון תצוגה כשלעצמו אינו קוטע את הקריינות. השמעה חוזרת, ניווט או הפעולה התקפה הבאה של הילד יכולים להפסיק את המשוב הקודם. בגן המילים ההתקדמות האוטומטית מחכה להדגמת המשפט השלם ולנסיעת הרכבת. איכות ההגייה עשויה להשתנות בין מכשירים וקולות.

באייפד ובאייפון, וגם בגן המילים בכל הדפדפנים, הקריינות אינה תלויה במנוע הקול של הדפדפן. מתוך מחוות המשתמש הראשונה נפתח הערוץ שמשמיע את צלילי המשחק ומקטעי הקריינות המקומיים. המקטעים בשלוש גרסאות הקול ארוזים בשלושה קובצי שמע ובמפת מקטעים תחת `public/speech/`. קבצים אלה נכללים מראש במטמון של ה־service worker, ולכן הקריינות פועלת גם ללא חיבור לרשת. תקלה בהשמעת מקטע בגן המילים אינה עוצרת את הרכבת.

פתיחת מנגנון השמע רק מחזירה לפעולה את ה־`AudioContext`. קובץ הקול של השפה המבוקשת נטען ומפוענח רק בהקראה הראשונה, ובכל זמן נשמר בזיכרון לכל היותר קובץ שפה מפוענח אחד. מעבר שפה משחרר את ההפניה לקובץ הקודם, ובקשות מקבילות לאותה שפה חולקות פעולת טעינה ופענוח אחת.

`src/content/recordedSpeechCatalog.ts` מפיק את רשימת המשפטים מאותם מקורות ובוני משפטים שבהם משתמשים המשחקים. בדיקת כיסוי מחייבת התאמה מלאה בין הקטלוג למפה שנוצרה. לאחר שינוי תוכן דיבור מייצרים מחדש את הנכסים המקומיים:

המחולל משתמש ב־Azure Neural Text to Speech דרך Microsoft Entra ID בלבד. נדרשים Azure CLI מחובר, תפקיד `Cognitive Services Speech User` על משאב בעל custom domain, ו־FFmpeg. אין צורך במפתח או בסוד:

```bash
az login
export AZURE_SPEECH_RESOURCE_ID="$(az cognitiveservices account show \
  --name <resource-name> \
  --resource-group <resource-group> \
  --query id -o tsv)"
export AZURE_SPEECH_REGION="<region>"
npm run generate:speech
```

במשאב מהמסלול החינמי מגדירים `AZURE_SPEECH_F0=true` כדי להגביל את קצב בקשות הסינתזה לעשרים בדקה.

הקולות הם `he-IL-HilaNeural`, `en-US-AnaNeural` ו־`en-GB-MaisieNeural`. שני הקולות באנגלית מסווגים על ידי Azure כקולות ילדה, וברירת המחדל היא `en-US-AnaNeural`. ל־Azure אין קול ילד עברי מסווג במערך הזמין, ולכן העברית נשארת עם `he-IL-HilaNeural`. מחולל הקריינות מקבל אסימון Entra, מייצר מקטעים מרשימת משפטים קבועה ואינו קורא תמונות, הקלטות או נתונים מקומיים של משתמשים.

בעת חזרה לגרסה קודמת יש לסגור לשוניות ישנות ולפתוח את האפליקציה מחדש. גרסה ישנה מסוגלת לכתוב מחדש נתוני התקדמות משותפים מתוך לשונית שלא רועננה, ללא דרך להבחין בין כתיבה שכזאת לאיפוס. טעינה רגילה של גרסה ישנה מתוך הרשומה העדכנית אינה דורסת את השלבים המורחבים השמורים בנפרד.

לתיקון הגייה מגדירים `AZURE_SPEECH_REGENERATE_MATCH` למילת המקור הלא־מנוקדת. להוספת משפטים חסרים בלבד משתמשים במקום זאת ב־`AZURE_SPEECH_GENERATE_MISSING=true`. בשני המצבים נדרש שם חבילה חדש וממוספר, למשל `AZURE_SPEECH_PACK=garden-stories-v1`. המחולל מקליט רק את המשפטים שנבחרו, שומר אותם בקובץ נפרד לכל שפה ומעדכן את המפה בלי לקודד מחדש הקלטות אחרות. יש להוסיף את הקבצים למטמון הלא־מקוון, לעדכן את גרסת כתובת המפה ובדיקות החתימות, ולהריץ `npm run validate:speech`. הבדיקה מאמתת קבצים וגבולות השמעה, לא הטעמה: לשם כך יש להאזין למקטע מתוך הקובץ המקודד.

## הערה חשובה

הפרויקט מיועד לחוויה משחקית ולמידה עדינה בלבד. הוא לא מציג טענות רפואיות, טיפוליות או אבחוניות, אינו טוען שהוא ממצה או מאושר על ידי אף גורם מקצועי, ואינו תחליף לשיחה ולמשחק משותף עם מבוגר.
